# 八字真言 MVP

这是一个零依赖、可直接运行的「八字真言」网站。它实现出生资料、排盘、试读、完整报告与图片保存流程。

## 已实现

- 抖音自然流量 H5 入口与古籍卷轴风响应式页面
- 出生日期、分钟、省市搜索、区县补充、性别、年龄及隐私同意表单
- 30 分钟一次性交接凭证与微信小程序 URL Link 适配入口
- 太阳视黄经节气切月、真太阳时近似校正、23:00 子初换日、四柱试算及五行表层计数
- 四柱细盘：主星、天干、地支、藏干、副星、十二长生、空亡与纳音
- 图像化结构报告：五行雷达、十神比例、表层承载结构、财星／官杀落位及原局地支关系
- 出生资料表单：1900 年至今的年月日滚轮、24 小时时分滚轮，以及中国大陆 31 个省级区域与地级市联动选择
- 排盘规则总览：真太阳时、23:00 子初换日与太阳视黄经节气切月
- 报告章节导航、命造资料条、时间校正卡、完整大运排表与当前大运标识
- 未来十年逐年婚姻／事业／财富分析，以及今年生活健康、贵人方位与行动时间参考
- 免费命盘与三项文化研习试读
- ¥9.9 演示订单、幂等订单字段、背景报告生成状态机
- 网页完整报告及分章可下载 PNG 报告图片
- AI 显式标识、365 日报告期限、24 小时未承接资料清理和主动删除
- 古籍来源人工核验后台、订单任务、境内接口配置和本地事件记录

## 线上网址

正式自订网域：`https://www.wen-truth.cn/`

网站以 GitHub Pages 发布；DNS 生效前可先使用 GitHub Pages 提供的预览网址。

## 启动

在 PowerShell 进入本目录后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

浏览器打开 `http://127.0.0.1:4173/`。

也可直接双击 `index.html`，但建议使用本地服务器测试 URL Link、下载和浏览器权限。

## 重要限制

1. 当前排盘以太阳视黄经判定十二节的切月时刻，接近节气边界时会明确警告；正式发布前仍须使用高精度天文历表交叉验证并通过至少 200 组权威案例。
2. 微信登录、URL Link、JSAPI 支付、腾讯模型、KMS、数据库、COS 和自动退款只有接口位置，没有凭证时不会伪装成功。
3. 演示订单不会产生真实交易；真实付款仍需配置微信小程序与微信支付接口。
4. 古籍库初始为空。没有命理师核验书名、版本、篇章和页码时，系统不引用任何古籍原文。
5. 前端 `localStorage` 只用于原型验证，不适合生产敏感资料。生产版必须迁移至境内 API、加密数据库与 KMS。
6. 目前省市名单内置到地级行政区，区县采用补充输入；生产版应接入有授权的境内行政区划服务及区县中心经纬度。

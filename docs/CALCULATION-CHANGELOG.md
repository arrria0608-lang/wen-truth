# 排盘算法变更记录

## prototype-astronomy-v0.2

- 修复月柱在每月交节日前可能错误回落到丑月的问题。
- 根因：旧版节气数组按二月至十二月、一月排列；查询「本月交节日前最近的上一节」时使用数组最后一项，误把一月小寒当成上一节。
- 月建改为按出生时刻的太阳视黄经计算：立春 315° 起寅月，每 30° 进入下一月。
- 新增节气边界警告；距离交节黄经不足 0.35° 时要求以高精度历表复核。
- 新增四柱细盘：十神、藏干、副星、十二长生、各柱空亡及纳音。

### 回归案例

阳历 `1994-09-04 13:58`（北京时区测试点）应为：

`甲戌　壬申　癸巳　己未`

其中太阳视黄经约为 `161.49°`，尚未到白露 `165°`，因此仍属申月；甲年申月的月干为壬，月柱为壬申。
